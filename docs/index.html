AirDeck

Features

Everything you need to automate your workflow

Four physical buttons. Unlimited actions. Works over USB or Wi-Fi.

Dual Mode Support

Connect via USB with an Arduino Uno, Nano, or Mega over Serial, or go cable-free with a NodeMCU / D1 Mini over UDP Wi-Fi. Same JSON config format for both.

Shell Commands

Trigger any terminal command on button press. Reboot, run scripts, launch apps, or chain commands with &&.

Automated Typing

Send text strings or code snippets directly to your active window. Paste boilerplate, commands, or entire paragraphs with one press.

Key Emulation

Map buttons to any keyboard key: Space, Enter, F5, arrow keys, media controls. Works with any application that accepts keyboard input.

Web Shortcuts

Launch any URL in your default browser instantly. One button can open your dashboard, a pull request, or a monitoring page.

Background Service

Register AirDeck as a systemd service and it starts automatically on every boot, with no terminal window required.

Pick your connection

Both modes use the same four-button wiring and the same JSON config format. Choose based on what you have.

Wired

Arduino via USB

  • ControllerUno, Nano, or Mega
  • Buttons4x Tactile Push Buttons
  • ConnectionUSB Type A to B
  • PowerPowered via USB
  • Resistors neededNone (pull-up built in)
Wireless

ESP8266 via Wi-Fi

  • ControllerNodeMCU, D1 Mini, ESP-12
  • Buttons4x Tactile Push Buttons
  • ConnectionUDP over Wi-Fi
  • PowerUSB or 3.3V Battery
  • Resistors neededNone (pull-up built in)
Wiring: Connect all button GND legs to a common GND rail. Signal legs go to pins 2-5 (Arduino) or D1-D4 (ESP8266). Internal pull-up resistors are enabled in firmware - no external components needed.

Installation

Up and running in three steps

You need Python 3, a microcontroller, and the Arduino IDE. That's it.

01

Download your kit and flash the firmware

Pick your connection type. Download the kit, open the .ino sketch in the Arduino IDE, and flash your board. For ESP8266, edit ssid, password, and targetIP before uploading.

Wired

Arduino Kit

Uno, Nano, Mega via USB

Wireless

ESP8266 Kit

NodeMCU, D1 Mini via Wi-Fi

02

Install Python dependencies

Install the required Python packages. pynput handles input injection and pyserial handles the USB serial connection.

$ pip install pynput pyserial

# Or install from the requirements file
$ pip install -r Requirements.txt

X11 vs Wayland: X11 gives full functionality. On Wayland, shell commands and web shortcuts work, but key emulation and text typing may be blocked by the display server's security model.

03

Run the host script

Place the host script and config JSON (downloaded in Step 01) in the same folder, then run the script. Edit the JSON to customize your button mappings.

# Wired
$ python3 arduino_airdeck_wired.py

# Wireless
$ python3 esp8266_airdeck_wireless_host.py

Configuration

Map buttons to actions via JSON

Edit the config file - no recompiling, no reflashing. Change it anytime and restart the script.

command Run a terminal command
website Open a URL in browser

Run on boot with systemd

Register AirDeck as a service so it starts automatically. No terminal window needed after setup.

Create

Create the service file

Create a new service file in the systemd directory and paste your configuration with the correct script path.

$ sudo nano /etc/systemd/system/airdeck.service

Reload

Reload daemon

Tell systemd to re-read its service definitions after creating or modifying the file.

$ sudo systemctl daemon-reload

Enable

Enable and start

Enable the service to start at boot, then start it immediately without rebooting.

$ sudo systemctl enable airdeck.service
$ sudo systemctl start airdeck.service
